# LoRA（Low-Rank Adaptation）技术详解

> **一句话概括：冻结预训练权重，只训练两个小矩阵 A 和 B，用极低的参数量实现接近全量微调的效果。**

---

## 一、为什么需要 LoRA？

### 全量微调的困境

```
GPT-2 Large: 774M 参数
LLaMA-7B:    7B 参数
GPT-3:       175B 参数

全量微调 = 所有参数都要更新
```

| 问题 | 表现 |
|------|------|
| **显存爆炸** | 7B 模型全量微调需要 ~120GB 显存 |
| **存储冗余** | 每个任务存一份完整模型（7B × N 个任务） |
| **训练缓慢** | 参数越多，梯度计算越慢 |

### LoRA 的核心洞察

微软的研究者发现了一个重要现象：

> **预训练模型的权重更新矩阵是"低秩"的（low-rank），不需要更新全部参数。**

直觉理解：模型已经学到了通用知识，微调只是做"小幅调整"，这个调整不需要满秩矩阵来表达。

---

## 二、LoRA 的数学原理

### 原始的全量微调

对于一个预训练权重矩阵 $W_0 \in \mathbb{R}^{d \times k}$，微调后：

$$W = W_0 + \Delta W$$

其中 $\Delta W \in \mathbb{R}^{d \times k}$ 是更新量，参数量 = $d \times k$。

### LoRA 的低秩分解

LoRA 假设 $\Delta W$ 是**低秩**的，可以分解为两个小矩阵：

$$\Delta W = B \times A$$

其中：
- $A \in \mathbb{R}^{r \times k}$（降维矩阵）
- $B \in \mathbb{R}^{d \times r}$（升维矩阵）
- $r \ll \min(d, k)$（秩，通常 4~64）

```
全量微调:  ΔW ∈ ℝ^(d×k)        参数量 = d × k

LoRA:     ΔW = B × A
          B ∈ ℝ^(d×r), A ∈ ℝ^(r×k)   参数量 = d×r + r×k = r×(d+k)
```

### 参数量对比

以 GPT-2 的 `c_attn` 层为例（$d=768, k=2304$）：

| 方式 | 参数量 | 比例 |
|------|--------|------|
| 全量微调 | 768 × 2304 = **1,769,472** | 100% |
| LoRA (r=8) | 8 × (768 + 2304) = **24,576** | **1.4%** |
| LoRA (r=16) | 16 × (768 + 2304) = **49,152** | **2.8%** |

**参数量减少了 ~98%！**

## 三、LoRA 的结构图

### 单个线性层的 LoRA

```
输入 x ∈ ℝ^(1×k)
     │
     ├──────────────────────────────┐
     │                              │
     ▼                              ▼
┌─────────────┐              ┌─────────────┐
│  W₀ (冻结)  │              │  LoRA 分支   │
│  d × k      │              │             │
│  不更新权重  │              │  x → A → B  │
└──────┬──────┘              └──────┬──────┘
       │                            │
       │         × (α/r)            │
       │         缩放系数            │
       ▼                            ▼
       └───────────┬────────────────┘
                   │
                   ▼
            h = W₀x + (α/r)·B·A·x
```

### 关键公式

$$h = W_0 x + \frac{\alpha}{r} \cdot B A x$$

其中：
- $W_0 x$：原始预训练权重的输出（**冻结，不更新**）
- $\frac{\alpha}{r} \cdot B A x$：LoRA 的增量输出（**可训练**）
- $\frac{\alpha}{r}$：缩放系数，控制 LoRA 的影响强度

---

## 四、LoRA 的初始化策略

```
A: 使用高斯随机初始化（Kaiming 初始化）
B: 初始化为全零矩阵
```

**为什么 B 初始化为零？**

$$\Delta W = B \times A = 0 \times A = 0$$

训练开始时，LoRA 的输出为零，**模型行为与预训练模型完全一致**。随着训练进行，B 逐渐学到非零值，LoRA 才开始产生影响。

这保证了：
- 训练初期稳定性（不会因为随机初始化破坏预训练知识）
- 渐进式学习（从"不变"到"微调"）

## 五、LoRA 超参数详解

### 1. `r`（rank）— 秩

```python
LoraConfig(r=8, ...)
```

| 值 | 效果 |
|----|------|
| r=4 | 参数最少，适合简单任务 |
| r=8 | 推荐起点，平衡效率和性能 |
| r=16 | 更强表达能力，适合复杂任务 |
| r=64 | 接近全量微调，参数量也接近 |

### 2. `lora_alpha` — 缩放因子

```python
LoraConfig(lora_alpha=16, ...)
```

缩放系数 = $\frac{\alpha}{r}$

| 设置 | 效果 |
|------|------|
| alpha = r (1:1) | LoRA 影响较小 |
| alpha = 2r (2:1) | **推荐**，LoRA 影响适中 |
| alpha = 4r | LoRA 影响较大 |

### 3. `lora_dropout` — Dropout 比率

```python
LoraConfig(lora_dropout=0.05, ...)
```

在 LoRA 分支中随机丢弃部分神经元，防止过拟合。

### 4. `target_modules` — 目标模块

```python
LoraConfig(target_modules=["c_attn", "c_proj", "c_fc"], ...)
```

指定哪些层加 LoRA。选择原则：**Attention + MLP 的线性层**。

## 七、训练 vs 推理

### 训练时

```
模型参数:
├── 预训练权重 W₀    → 冻结 ❄️（requires_grad=False）
├── LoRA 矩阵 A      → 可训练 🔥（requires_grad=True）
├── LoRA 矩阵 B      → 可训练 🔥（requires_grad=True）
└── 分类头 (score)   → 可训练 🔥（requires_grad=True）

前向传播: h = W₀x + (α/r)·B·A·x
反向传播: 只更新 A、B、分类头
```

### 推理时（合并后）

```python
merged_model = model.merge_and_unload()
```

合并操作：

$$W_{merged} = W_0 + \frac{\alpha}{r} \cdot B \cdot A$$

```
合并后:
├── W_merged = W₀ + (α/r)·B·A  → 单一权重矩阵
└── 没有额外的 LoRA 分支了

推理速度: 与原始模型完全一致（无额外开销）
```

## 十一、深入理解 Rank（秩）

### Rank 是什么？

Rank（秩）是线性代数中矩阵"有效维度"的概念。在 LoRA 中，它决定了 **A 和 B 矩阵的中间维度**。

```
W₀ ∈ ℝ^(d×k)     原始权重矩阵，维度 d×k

A ∈ ℝ^(r×k)       降维矩阵
B ∈ ℝ^(d×r)       升维矩阵
     ↑
   rank = r，这就是 LoRA 的"瓶颈"
```

### 直觉理解

把 rank 想象成"信息通道的宽度"：

```
rank = 4:   4 条通道    少，信息压缩严重，适合简单任务
rank = 8:   8 条通道    适中，推荐起点
rank = 16:  16 条通道   多，表达能力强
rank = 64:  64 条通道   很多，接近全量微调
rank = 768: 768 条通道  等于原始维度，退化为全量微调
```

### 信息流动过程

```
输入 x ∈ ℝ^(1×k)，k=2304
     │
     ▼
┌─────────────────┐
│  A ∈ ℝ^(r×k)   │  ← 降维：把 2304 维压缩到 r 维
│  (压缩)         │
└────────┬────────┘
         │
         ▼
    中间向量 ∈ ℝ^(1×r)   ← 瓶颈！只有 r 维
         │
         ▼
┌─────────────────┐
│  B ∈ ℝ^(d×r)   │  ← 升维：把 r 维扩展回 768 维
│  (解压)         │
└────────┬────────┘
         │
         ▼
输出 ∈ ℝ^(1×d)，d=768
```

### Rank 与参数量的关系

以 GPT-2 的 `c_attn` 层为例（d=768, k=2304）：

| Rank | A 参数量 | B 参数量 | 总参数量 | 相比全量微调 |
|------|---------|---------|---------|-------------|
| r=4 | 4×2304=9,216 | 768×4=3,072 | **12,288** | 0.7% |
| r=8 | 8×2304=18,432 | 768×8=6,144 | **24,576** | 1.4% |
| r=16 | 16×2304=36,864 | 768×16=12,288 | **49,152** | 2.8% |
| r=64 | 64×2304=147,456 | 768×64=49,152 | **196,608** | 11.1% |
| r=768 | 768×2304=1,769,472 | 768×768=589,824 | **2,359,296** | 133% |

### 为什么低秩有效？

**核心假设**：预训练模型微调时，权重更新 $\Delta W$ 是低秩的。

```
全量微调的 ΔW:
┌───────────────────────┐
│ ▓░▓░░▓░▓▓░░▓░▓░▓░░▓░ │
│ ░▓░░▓░▓░░▓▓░░▓░▓░▓░░ │  ← 看起来很复杂
│ ▓░▓▓░░▓░▓░░▓░▓▓░░▓░▓ │
│ ░▓░░▓░░▓░▓▓░░▓░░▓░▓░ │
└───────────────────────┘

但其实可以用低秩矩阵近似:
B × A ≈ ΔW
┌───┐   ┌───────────────┐
│ ▓ │   │ ░░▓░░▓░▓░░▓░░ │
│ ░ │ × │ ▓░░▓░▓░░▓▓░░▓ │  ≈ 99% 的效果
│ ▓ │   │ ░▓░░▓░▓░░▓░▓░ │
│ ░ │   │ ▓░▓░░▓░▓▓░░▓░ │
└───┘   └───────────────┘
  B         A
(4×2304)  (768×4)
```

直觉：微调只是在预训练知识的基础上做"小幅调整"，这个调整可以用少量"方向"（rank）来表达。

## 十二、前向传播详解

### 单个线性层的前向传播

假设原始线性层：$y = W_0 x$

加入 LoRA 后：

$$y = W_0 x + \frac{\alpha}{r} \cdot B A x$$

**分步计算**：

```
输入: x ∈ ℝ^(1×k)，例如 k=2304

Step 1: 原始路径（冻结）
        y₀ = W₀ × x
        W₀ ∈ ℝ^(d×k), x ∈ ℝ^(k×1)
        y₀ ∈ ℝ^(d×1)     d=768

Step 2: LoRA 路径（可训练）
        2a. A 矩阵降维
            z = A × x
            A ∈ ℝ^(r×k), x ∈ ℝ^(k×1)
            z ∈ ℝ^(r×1)     r=8

        2b. B 矩阵升维
            y_lora = B × z
            B ∈ ℝ^(d×r), z ∈ ℝ^(r×1)
            y_lora ∈ ℝ^(d×1)   d=768

        2c. 缩放
            y_lora = (α/r) × y_lora
            α=16, r=8, 所以 α/r = 2

Step 3: 合并输出
        y = y₀ + y_lora
        y ∈ ℝ^(d×1)
```

### 完整 Transformer Block 的前向传播

```
输入: hidden_states ∈ ℝ^(batch×seq×768)
         │
         ▼
┌─────────────────────────────────────────────────┐
│              Self-Attention Block                 │
│                                                   │
│  ① QKV 投影 (c_attn: 768 → 2304)               │
│     输入: x ∈ ℝ^(batch×seq×768)                  │
│                                                   │
│     原始: qkv = W₀ × x           ← 冻结         │
│     LoRA: z = A × x              ← 可训练        │
│           z_lora = B × z         ← 可训练        │
│           qkv = qkv + (α/r)×z_lora              │
│                                                   │
│     输出: qkv ∈ ℝ^(batch×seq×2304)               │
│     拆分: Q, K, V = chunk(qkv, 3)               │
│     每个 ∈ ℝ^(batch×seq×768)                     │
│                                                   │
│  ② 注意力计算                                    │
│     attn = softmax(Q×K^T / √d) × V              │
│     attn ∈ ℝ^(batch×seq×768)                     │
│                                                   │
│  ③ 输出投影 (c_proj: 768 → 768)                  │
│     原始: out = W₀ × attn        ← 冻结         │
│     LoRA: z = A × attn           ← 可训练        │
│           z_lora = B × z         ← 可训练        │
│           out = out + (α/r)×z_lora               │
│                                                   │
│     输出: out ∈ ℝ^(batch×seq×768)                │
└───────────────────────┬───────────────────────────┘
                        │ + residual
                        ▼
┌─────────────────────────────────────────────────┐
│              Feed-Forward Block                   │
│                                                   │
│  ④ 扩张层 (c_fc: 768 → 3072)                     │
│     原始: h = W₀ × out          ← 冻结          │
│     LoRA: z = A × out           ← 可训练         │
│           z_lora = B × z        ← 可训练         │
│           h = h + (α/r)×z_lora                   │
│                                                   │
│  ⑤ 激活函数                                      │
│     h = GELU(h)                                   │
│                                                   │
│  ⑥ 压缩层 (c_proj: 3072 → 768)                   │
│     原始: h_out = W₀ × h         ← 冻结         │
│     LoRA: z = A × h             ← 可训练         │
│           z_lora = B × z        ← 可训练         │
│           h_out = h_out + (α/r)×z_lora           │
│                                                   │
│     输出: h_out ∈ ℝ^(batch×seq×768)              │
└───────────────────────┬───────────────────────────┘
                        │ + residual
                        ▼
                   下一层输入
```

## 十三、反向传播详解

### 关键前提

```
训练时的参数状态:
├── W₀ (原始权重)    → requires_grad = False ❄️
├── A (LoRA 降维)    → requires_grad = True  🔥
├── B (LoRA 升维)    → requires_grad = True  🔥
└── score (分类头)   → requires_grad = True  🔥
```

### 反向传播的目标

已知损失函数 $L$ 对输出 $y$ 的梯度 $\frac{\partial L}{\partial y}$，需要计算：

- $\frac{\partial L}{\partial A}$：更新 A 矩阵
- $\frac{\partial L}{\partial B}$：更新 B 矩阵

### 数学推导

前向传播公式：

$$y = W_0 x + \frac{\alpha}{r} \cdot B A x$$

令 $z = Ax$（LoRA 的中间结果），则：

$$y = W_0 x + \frac{\alpha}{r} \cdot B z$$

**对 B 求梯度**：

$$\frac{\partial L}{\partial B} = \frac{\partial L}{\partial y} \cdot \frac{\partial y}{\partial B} = \frac{\partial L}{\partial y} \cdot \frac{\alpha}{r} \cdot z^T$$

```
已知: ∂L/∂y ∈ ℝ^(d×1)
      z = Ax ∈ ℝ^(r×1)

计算: ∂L/∂B = (α/r) × (∂L/∂y) × z^T
      ∂L/∂B ∈ ℝ^(d×r)
```

**对 A 求梯度**（链式法则）：

$$\frac{\partial L}{\partial A} = \frac{\partial L}{\partial z} \cdot \frac{\partial z}{\partial A} = \left(\frac{\alpha}{r} \cdot B^T \cdot \frac{\partial L}{\partial y}\right) \cdot x^T$$

```
已知: ∂L/∂y ∈ ℝ^(d×1)
      B ∈ ℝ^(d×r)
      x ∈ ℝ^(k×1)

计算: ∂L/∂z = (α/r) × B^T × (∂L/∂y)    ∈ ℝ^(r×1)
      ∂L/∂A = (∂L/∂z) × x^T             ∈ ℝ^(r×k)
```

### 反向传播流程图

```
前向传播:
    x ──→ A ──→ z ──→ B ──→ (α/r)×Bz ──→ + ──→ y
                                           ↑
                                          W₀x (冻结，不参与反向传播)

反向传播:
    ∂L/∂y
      │
      ├──────────────────────────┐
      │                          │
      ▼                          ▼
┌─────────────┐          ┌─────────────┐
│ ∂L/∂B       │          │ ∂L/∂(α/r·Bz)│
│ = (α/r)·    │          │ = ∂L/∂y     │
│ (∂L/∂y)·z^T│          │             │
│             │          │             │
│ B ∈ ℝ^(d×r) │          │             │
└──────┬──────┘          └──────┬──────┘
       │                        │
       │ (保存用于更新B)         ▼
       │                ┌─────────────┐
       │                │ ∂L/∂z       │
       │                │ = (α/r)·    │
       │                │   B^T·∂L/∂y │
       │                │             │
       │                │ z ∈ ℝ^(r×1) │
       │                └──────┬──────┘
       │                       │
       │                       ▼
       │                ┌─────────────┐
       │                │ ∂L/∂A       │
       │                │ = (∂L/∂z)·  │
       │                │   x^T       │
       │                │             │
       │                │ A ∈ ℝ^(r×k) │
       │                └──────┬──────┘
       │                       │
       │ (保存用于更新A)        │
       ▼                       ▼
    参数更新:              参数更新:
    B ← B - lr×∂L/∂B     A ← A - lr×∂L/∂A
```

### 具体数值示例

假设 GPT-2 的 `c_attn` 层（d=768, k=2304, r=8, α=16）：

```
前向传播:
输入: x ∈ ℝ^(2304×1)

Step 1: z = A × x
        A ∈ ℝ^(8×2304), x ∈ ℝ^(2304×1)
        z ∈ ℝ^(8×1)

Step 2: y_lora = B × z
        B ∈ ℝ^(768×8), z ∈ ℝ^(8×1)
        y_lora ∈ ℝ^(768×1)

Step 3: y_lora = (16/8) × y_lora = 2 × y_lora

Step 4: y = W₀x + y_lora
        y ∈ ℝ^(768×1)

反向传播:
已知: ∂L/∂y ∈ ℝ^(768×1)

Step 1: ∂L/∂B = 2 × (∂L/∂y) × z^T
        ∂L/∂y ∈ ℝ^(768×1), z^T ∈ ℝ^(1×8)
        ∂L/∂B ∈ ℝ^(768×8)    ← B 的梯度

Step 2: ∂L/∂z = 2 × B^T × (∂L/∂y)
        B^T ∈ ℝ^(8×768), ∂L/∂y ∈ ℝ^(768×1)
        ∂L/∂z ∈ ℝ^(8×1)

Step 3: ∂L/∂A = (∂L/∂z) × x^T
        ∂L/∂z ∈ ℝ^(8×1), x^T ∈ ℝ^(1×2304)
        ∂L/∂A ∈ ℝ^(8×2304)   ← A 的梯度

参数更新:
A ← A - 0.0005 × ∂L/∂A    (lr=5e-4)
B ← B - 0.0005 × ∂L/∂B
```

### 为什么 W₀ 不需要梯度？

```
y = W₀x + (α/r)·B·A·x
    ↑              ↑
  冻结项         可训练项

∂L/∂W₀ = ∂L/∂y × ∂y/∂W₀ = ∂L/∂y × x

虽然数学上可以算，但:
1. W₀.requires_grad = False，PyTorch 不会计算它的梯度
2. 即使算出来也不更新（optimizer 只更新 A 和 B）
3. 节省显存（不用存储 W₀ 的梯度）
```

## 十四、完整的一次训练 Step

```
Step 1: 前向传播
        ┌─────────────────────────────────────┐
        │ 输入: batch = {input_ids,           │
        │              attention_mask,         │
        │              labels}                 │
        │                                      │
        │ 模型计算:                             │
        │   hidden = Embedding(input_ids)      │
        │   for layer in transformer_blocks:   │
        │     hidden = layer(hidden)           │
        │     ↑ 每层都有 LoRA 参与              │
        │   logits = score(hidden)             │
        │   loss = CrossEntropy(logits, labels)│
        └─────────────────────────────────────┘

Step 2: 反向传播
        ┌─────────────────────────────────────┐
        │ loss.backward()                      │
        │                                      │
        │ PyTorch 自动计算:                     │
        │   ∂L/∂A_i (每层的 A 矩阵梯度)        │
        │   ∂L/∂B_i (每层的 B 矩阵梯度)        │
        │   ∂L/∂score (分类头梯度)              │
        │                                      │
        │ W₀ 的梯度: 不计算（requires_grad=False）│
        └─────────────────────────────────────┘

Step 3: 参数更新
        ┌─────────────────────────────────────┐
        │ optimizer.step()                     │
        │                                      │
        │ 更新: A_i ← A_i - lr × ∂L/∂A_i     │
        │ 更新: B_i ← B_i - lr × ∂L/∂B_i     │
        │ 更新: score ← score - lr × ∂L/∂score│
        │                                      │
        │ 冻结: W₀ 不变                        │
        └─────────────────────────────────────┘

Step 4: 清零梯度
        ┌─────────────────────────────────────┐
        │ optimizer.zero_grad()                │
        │ 为下一个 step 准备                    │
        └─────────────────────────────────────┘
```

## 总结

| 概念 | 要点 |
|------|------|
| **Rank** | 决定 A、B 矩阵的中间维度，r 越大表达能力越强但参数越多 |
| **前向传播** | $y = W_0x + \frac{\alpha}{r} \cdot BAx$，原始路径 + LoRA 路径相加 |
| **反向传播** | 只对 A、B 求梯度，W₀ 冻结不参与；梯度通过链式法则从输出传到 A 和 B |
| **参数更新** | 只更新 A、B、分类头，W₀ 保持不变 |

```
LoRA = 用两个小矩阵（A 和 B）来"近似"权重更新
     = 把 ΔW 从 d×k 降到 r×(d+k)
     = 用 1% 的参数达到 99% 的效果
     = 冻结大模型，只训练小外挂
```
